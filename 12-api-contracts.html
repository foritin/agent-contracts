API 契约

概述

本文档定义公共模块之间、以及公共模块与应用程序之间的 API 契约。
确保 Charter 和 Hermes 可以无缝使用这些共享模块。

1. LLM Provider API

1.1 Trait 定义

rust
#[async_trait]
pub trait LlmProvider: Send + Sync {
    async fn complete(&self, request: CompletionRequest) 
        -> Result<CompletionResponse>;
    
    async fn stream(&self, request: CompletionRequest) 
        -> Result<BoxStream<'static, StreamEvent>>;
    
    fn capabilities(&self) -> Capabilities;
    fn name(&self) -> &str;
}

1.2 请求/响应格式

rust
pub struct CompletionRequest {
    pub model: String,
    pub system: Option<String>,
    pub messages: Vec<Message>,
    pub tools: Vec<ToolSpec>,
    pub max_tokens: u32,
    pub temperature: Option<f32>,
    pub enable_caching: bool,
}

pub struct CompletionResponse {
    pub content: Vec<ContentBlock>,
    pub stop_reason: StopReason,
    pub usage: Usage,
}

pub enum StreamEvent {
    TextDelta { text: String },
    ToolUseStart { id: String, name: String },
    ToolUseDelta { id: String, input_json: String },
    ToolUseComplete { id: String, input: Value },
    Stop { reason: StopReason },
    Usage(Usage),
}

1.3 错误处理

rust
pub enum LlmError {
    ApiError { status: u16, message: String },
    RateLimited { retry_after: u64 },
    AuthFailed(String),
    ModelNotFound(String),
    ConnectionFailed(String),
    Timeout,
    ParseError(String),
}

2. Session Store API

2.1 Trait 定义

rust
#[async_trait]
pub trait SessionStore: Send + Sync {
    async fn create(&self, model: &str, provider: &str) -> Result<Session>;
    async fn load(&self, id: &str) -> Result<Session>;
    async fn append(&self, id: &str, event: SessionEvent) -> Result<()>;
    async fn list(&self) -> Result<Vec<SessionMeta>>;
    async fn delete(&self, id: &str) -> Result<()>;
    async fn archive(&self, id: &str) -> Result<()>;
    async fn recover(&self, id: &str) -> Result<Session>;
}

2.2 事件类型

rust
pub enum SessionEvent {
    Meta(SessionMeta),
    Message(Message),
    Usage(Usage),
    ToolCall { name: String, input: Value },
    ToolResult { call_id: String, output: Value, is_error: bool },
    System { event: String, data: Value },
}

6. IPC API

6.1 协议

jsonc
// 请求
{
  "jsonrpc": "2.0",
  "id": "req-1",
  "method": "tool.execute",
  "params": { "name": "read_file", "input": { "path": "/foo.txt" } }
}

// 响应
{
  "jsonrpc": "2.0",
  "id": "req-1",
  "result": { "content": "Hello World" }
}

// 事件（无 id）
{
  "jsonrpc": "2.0",
  "method": "agent.event",
  "params": { "type": "message", "text": "Hello" }
}

8. Error API

8.1 错误类型

rust
#[derive(Debug, thiserror::Error)]
pub enum Error {
    // 会话
    #[error("session not found: {0}")]
    SessionNotFound(String),
    #[error("session is locked: {0}")]
    SessionLocked(String),
    #[error("invalid session format: {0}")]
    InvalidSession(String),
    
    // Provider
    #[error("provider error: {0}")]
    Provider(String),
    #[error("API error: {status} - {message}")]
    ApiError { status: u16, message: String },
    #[error("rate limited, retry after {retry_after}s")]
    RateLimited { retry_after: u64 },
    #[error("authentication failed: {0}")]
    AuthFailed(String),
    
    // 工具
    #[error("tool error: {0}")]
    ToolHost(String),
    #[error("tool not found: {0}")]
    ToolNotFound(String),
    #[error("permission denied: {0}")]
    PermissionDenied(String),
    #[error("risk level too high: {level}")]
    RiskTooHigh { level: String },
    
    // MCP
    #[error("MCP error: {0}")]
    Mcp(String),
    #[error("MCP server not connected: {0}")]
    McpNotConnected(String),
    
    // 配置
    #[error("config error: {0}")]
    Config(String),
    #[error("config file not found: {0}")]
    ConfigNotFound(PathBuf),
    
    // 存储
    #[error("storage error: {0}")]
    Storage(String),
    #[error("IO error: {0}")]
    Io(#[from] std::io::Error),
    
    // 序列化
    #[error("JSON error: {0}")]
    Json(#[from] serde_json::Error),
    #[error("YAML error: {0}")]
    Yaml(#[from] serde_yaml::Error),
    #[error("TOML error: {0}")]
    Toml(#[from] toml::de::Error),
    
    // IPC
    #[error("IPC error: {0}")]
    Ipc(String),
    #[error("IPC timeout")]
    IpcTimeout,
    
    // 压缩
    #[error("compaction failed: {0}")]
    Compaction(String),
    
    // 其他
    #[error("internal error: {0}")]
    Internal(String),
    #[error("{0}")]
    Other(String),
}

pub type Result<T> = std::result::Result<T, Error>;

10. 数据流契约

10.1 Agent 事件流

text
User → GUI → IPC → Agent Loop → LLM Provider
              ← StreamEvent ←
GUI ← IPC ← Event Translation ←

10.2 工具调用流

text
LLM → ToolUse → Agent Loop → ToolHost → MCP Server / Gateway
       ToolResult ← Agent Loop ← ToolHost ←

10.3 会话持久化

text
Session Event → SessionStore → JSONL File
                              ← Load on startup

版本策略

  • 公共模块遵循语义化版本（Semver）
  • Charter 和 Hermes 可锁定特定版本
  • 破坏性变更需主版本号递增
本页为可离线浏览的重构规范；代码示例是实现合同，不是已交付源码。
