公共模块总览

1. 背景

R-Code（桌面 Agentic IDE）和 Hermes（自进化 AI Agent）共享大量底层基础设施。
这些共享模块被提取到 agent-core 目录，作为独立 crate 供两个项目共同使用。

2. 模块清单

2.1 核心模块

Crate说明依赖
agent-contract核心抽象（Session、Message、ToolHost、Provider trait）无
agent-llmLLM Provider 实现（Anthropic、DeepSeek、OpenAI）agent-contract
agent-mcpMCP 客户端（rmcp 封装）agent-contract
agent-store持久化存储（JSONL、SQLite）agent-contract

2.2 工具模块

Crate说明依赖
agent-compaction上下文压缩（长对话管理）agent-contract
agent-error错误处理（thiserror 定义）无
agent-config配置管理（TOML + 环境变量）agent-error

2.3 应用模块

Crate说明依赖
agent-tauriTauri 应用壳agent-contract, agent-config
hermes-cliCLI 入口agent-contract, agent-config
agent-ipcIPC 传输层agent-contract

3. 特性矩阵

特性R-Code 使用Hermes 使用说明
LLM Provider 抽象✅✅trait + Anthropic/OpenAI 实现
Session JSONL✅✅崩溃可恢复
ToolHost trait✅✅工具聚合抽象
MCP 客户端✅✅rmcp 封装
Compaction✅✅上下文压缩（Hermes 内聚在 core）
Tauri 壳✅✅窗口/菜单/命令
错误处理✅✅Hermes 内聚在 core
配置管理✅✅Hermes 内聚在 llm
IPC 传输（Unix Socket/Pipe）✅❌R-Code Main↔Worker 专用；Hermes 用 HTTP/WS（hermes-server）

不在公共层的项目特有模块：

  • R-Code：Tool Gateway、Permission Engine、Terminal、Pi Adapter、Task 状态机（见 r-code/）
  • Hermes：hermes-turn（执行引擎）、hermes-tools（内置工具）、hermes-server（HTTP/WS）、
    反思、记忆、Skills、IM bot（见 tiny-hermes/）
