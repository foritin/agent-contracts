Crate 映射表

概述

本文档定义新 Rust crate 与原始 TypeScript 包之间的映射关系，
以及两个项目（R-Code 和 Hermes）如何使用这些 crate。

范围边界：agent-core/crates/ 下的 crate（agent-error/contract/llm/mcp/store/config/compaction/ipc/tauri）是公共层，不含产品私有功能。下文 r-code-*、hermes-turn/tools/server 等是产品层 crate，由各产品仓库维护，不在 agent-core 范围内；此处列出仅为迁移参考。
